# Archived Lite evidence

Historical evidence copied from the ARA Lite work remains under each package's
`docs/evidence` directory. The extraction commit is recorded in
[`docs/migration/source.md`](../../migration/source.md).

The records retain their original package names, machine paths, timestamps, and
acceptance status. They are useful for provenance and regression research. They
do not establish current Morrow acceptance or a release claim.
