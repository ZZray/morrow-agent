Reach Desk 被控端安装包

在协助机上跑起来，立刻接入工作台

下载一个程序直接运行。它自己就是被控端进程，默认在前台。关掉窗口即退出。

打开工作台 查看安装包
一次性协助 推荐
  1. 下载对应系统的程序。ARM 设备（Ubuntu 等）选 ARM Linux（Ubuntu），文件名 handwave-linux-arm64.zip
  2. 直接运行这一个程序：Windows 双击，或 handwave node；Ubuntu 上 chmod +x handwave && ./handwave
  3. 安装为服务：handwave node install --hub <地址> --token <入网令牌>（Windows 管理员 / Linux root）。卸载：handwave node uninstall
  4. 不装服务、只要开机启动：handwave node autostart，关闭用 handwave node autostart --off
  5. 内置守护（脱离终端，退出后自己拉起）：handwave node --daemon
  6. 回到工作台右侧「远程主机」→「允许」再「接入」
默认
前台程序

直接运行。需要开机拉起同一个程序时用 node autostart，不必先装服务。

可选
系统服务 / 内置守护

node install --hub --token 交给系统服务并开机启动。node --daemon 则由程序自己守护。两者不要同时开。

安装包 按系统选择 · 校验可加 ?sha=1

包名形如 handwave-windows-amd64.zip；ARM Linux（Ubuntu）是 handwave-linux-arm64.zip。服务、开机启动和内置守护都是这一个程序，用 --hub / --token 指定云端。
