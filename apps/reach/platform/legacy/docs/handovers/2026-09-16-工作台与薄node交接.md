## 1. 一句话现状

本会话把产品从「终端控制台」推到 **聊天优先工作台**，并明确架构为 **Go 单二进制三件套**：云端 `hub` + 薄 `node`（被控端）+ 可选 `ctl`。本地 **不做 pi / 不做完整 agent**；会话与 AI 在 hub，工具在 node。Windows 上可把 node **装成服务**常驻。

---

## 2. 架构定案（已对齐）

```
浏览器工作台 ──HTTPS──> hub（认证 / 工作区·会话 / KB / AI 反代 / 信令中继）
                              ↑ WS
                            node（本机：入网、WebRTC/中继、exec·读写文件）
浏览器 ←── WebRTC DC（不通走中继）──→ node
```

| 选过的路 | 结论 |
|----------|------|
| 本机客户端拉起 pi 再同步云端 | **不做**（双状态、难同步） |
| 自写类似 pi/omp 的本地 agent | **不做**（换产品线） |
| **薄 node + 云端会话** | **采用**（与现仓库一致） |

说明：代码里的 **`node` = 被控端角色名**，不是 Node.js。语言是 **Go**，静态小包分发。

## 4. 关键行为备忘

1. **贴图/发送**：若已有工作区但无会话 → `ensureChatContext()` **自动新建会话**（不再只弹「请先选择工作区与会话」）。
2. **模型选择**：`Auto` 开关 + 悬浮菜单（搜索、勾选、无蓝色高亮）；悬停 tip + `Ctrl+/`。
3. **背景**：青灰/暖沙流光渐变，避免 AI 紫。
4. **输入框**：深色底 + 较高透明度（压白但不闷死透光）。
5. **node 服务**：安装需**管理员**；`node status` 无权限时会 Access denied。
6. **产品边界**：node 只 `exec` / 读 / 写；不跑本地模型循环。

1. **审一遍 diff → 按模块 commit**（工作台后端 / web UI / node 服务 / README），勿一次糊成巨大 commit。
