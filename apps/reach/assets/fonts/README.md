# 控制台字体

作者：Ray Zhang（Ray）。日期：2026-11-24。

`Outfit-wght.ttf` 是 Outfit 可变字体（字重 100–900），供 Web 控制台的拉丁字母和数字使用；中文仍回退到系统的微软雅黑。由 Reach 服务以 `/assets/outfit.ttf` 自托管，页面 CSP 只放开 `font-src 'self'`，不加载外部字体。
