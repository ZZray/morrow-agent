# Reach Desk 锁内观察、JSONL/SDK 与关闭复核

作者：Ray Zhang（Ray）。日期：2026-11-03。本轮只做本地开发和测试，没有服务器访问、远端模型请求、部署、安装、提交或推送。

## 实现及范围

在前一[Core 检查](desk-inspect-20261103.md)基础上接通共享协议。`platform/src/host.ts`、Store 和页面本轮均未改，**Desk 页面停止后自动续聊仍未接通**。基础 0/52、Desk 0/5 不变。

- Harness 新增 `inspect_session_locked(&InspectionRequest)`，返回持有 admission/close 同一把锁的 guard。观察 Core、fence 和 closing marker；只可能新建 advisory lock 文件，不迁移或清理原件。产物目录不能覆盖原生根或 Harness 命名空间。
- JSONL 新增 `inspect_session`，在 Start、token 和 MCP 处理前分流。结果完整保存为固定 `inspection.json`，控制帧只带引用与请求帧 SHA。整个 typed 外壳和换行共用 16 MiB 上限；超限拒绝，不截断。
- Node/Bun SDK 新增 `inspectSession`。先固定调用参数和目录，再等真实 process close、exit 0、唯一完整 UTF-8 终帧，核固定 lexical/real 根、文件 SHA、请求、范围、原生根、Core 指纹、Context 和调用者预算。结果父目录 junction 拒绝；缺失会话不能带旧 prefix 冒充新会话。
- 关闭声明可选 `session_inspection_ref`，须与 `evidence_refs` 一项的 path/SHA 相同。首次 prepared 前在关闭已持有的锁内直接重查同一 Core request 和原生事实，旧 fence 单独绑定。prepared/released 重试核旧存证，不读后来 Task 状态，不重入锁。
- 原 `interrupted_run` 与关闭 head 读取改为纯读，避免预检自身清除合法 migration marker。旧无 ref 声明继续兼容；显式 null 或未知字段不能序列化后静默丢弃。

主要入口：[Harness inspection](../../../../crates/ara-agent-lite-harness/src/inspection.rs)、[JSONL inspection](../../../../crates/ara-agent-lite-jsonl/src/inspection.rs)、[SDK inspection](../../../../crates/ara-agent-lite-jsonl/clients/node/inspection.mjs)及[关闭预检](../../../../crates/ara-agent-lite-jsonl/src/close.rs)。协议检查只陈述观察与交付，不接受 Task；Host 仍负责身份、实际执行 profile、baseline/admission、全部进程/callback join，以及外部效果结算。Hash 不是认证，advisory lock 不是 OS 沙箱。
